Neon Drift is a twin-stick arena survival shooter that runs entirely in the browser: pilot a lone neon ship through escalating waves of geometric hunters, chain kills to raise a combo multiplier up to x8, crack splitters into swarming minis, dodge orbiters that shoot back, and grab rapid-fire, shield and bomb drops to survive one wave longer. Canvas 2D rendering, synthesized WebAudio sound effects, keyboard + mouse controls, fully offline with zero dependencies.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 to play
node main.ts    # builds /output with the game files and dossier.json
```
